# BRO — Telegram Mini App вейп-шопа

Витрина вейп-шопа **BRO** в виде Telegram-бота с мини-приложением (Telegram WebApp):
каталог, избранное, корзина, промокоды, оформление заказа без предоплаты, профиль
с историей заказов и админ-панель. Реальная онлайн-оплата не подключена — заказ
уходит менеджеру, дальше всё как в магазине: «зашёл → выбрал → забрал».

Все файлы лежат плоско в корне репозитория — ничего распаковывать не нужно,
просто загрузите папку целиком на GitHub.

## Состав репозитория

```
main.py           — Flask-сервер: мини-апп, Telegram-бот (webhook) и API админ-панели
index.html        — интерфейс мини-приложения (18+ гейт, hero, каталог, корзина, заказ)
admin.html        — админ-панель (товары, заказы, вопросы, промокоды)
products.json     — каталог (админка читает и пишет в этот файл)
orders.json       — заказы (создаётся автоматически)
uploads/          — фото товаров, загруженные из админки
brand/            — логотип и графика BRO (SVG/PNG): bro-logo.svg, bro-avatar.png, bro-banner.png
requirements.txt  — python-зависимости
Procfile          — команда запуска для Render
render.yaml       — опциональный blueprint для Render
```

## Фирменный стиль

| Что | Значение |
| --- | --- |
| Фон | `#08050E` (чёрно-фиолетовый), карточки `#120D1C` |
| Основной акцент | электрик-фиолет `#9B5CFF` → спрей-розовый `#FF3D9A` (градиент кнопок и фильтров) |
| Корона / цены / «Хит» | золото `#FFC93C` |
| Успех / «В наличии» | лайм `#7CFF6B` |
| Заголовки и кнопки | Rubik 800–900 (капсом), акцентные блоки — Rubik Mono One |
| Текст | Inter |
| Элементы | «наклейки»-бейджи с жёсткой тенью, объёмные кнопки, бегущая строка, граффити-логотип |

Цвета и шрифты задаются переменными в начале `<style>` в `index.html` и `admin.html`
(`:root{ --accent-color … }`) — меняются в одном месте.

### Логотип

`brand/bro-logo.svg` — граффити-логотип BRO с короной и розовой тенью (векторный).
В `index.html` и `admin.html` он вшит как SVG-спрайт (`#bro-logo`), так что работает
без отдельных запросов. `brand/bro-avatar.png` (512×512) — для аватарки бота и канала,
`brand/bro-banner.png` (1280×640) — для обложки/превью.

## 1. Создайте бота

1. Откройте [@BotFather](https://t.me/BotFather) → `/newbot`, задайте имя (например, «BRO») и username.
2. Сохраните выданный **токен** (`BOT_TOKEN`).
3. `/setuserpic` → загрузите `brand/bro-avatar.png`.

## 2. Загрузите код на GitHub

Создайте репозиторий и загрузите все файлы из этой папки в корень.

## 3. Разверните на Render

1. [render.com](https://render.com) → **New → Web Service**, подключите репозиторий.
2. Сборка определится по `Procfile`, либо вручную:
   - **Build command:** `pip install -r requirements.txt`
   - **Start command:** `gunicorn main:app --bind 0.0.0.0:$PORT`
3. Переменные окружения (**Environment**):
   - `BOT_TOKEN` — токен из BotFather
   - `ADMIN_PASSWORD` — пароль для входа в админ-панель
   - `ADMIN_CHAT_ID` — ваш Telegram ID (узнать: [@userinfobot](https://t.me/userinfobot)); можно несколько через запятую: `111111,222222`. Эти аккаунты получают уведомления о заказах и кнопку «Панель администратора» в `/start`
   - `SHOP_CONTACT` — Telegram-аккаунт менеджера без `@` (по умолчанию `trushnyibro`); на него ведут кнопки «Написать менеджеру»
   - `WEBHOOK_URL` — необязательно; Render сам передаёт `RENDER_EXTERNAL_URL`
4. После первого старта вебхук Telegram устанавливается автоматически.

## 4. Проверьте бота

`/start` → «👑 Открыть BRO». Первым делом покажется экран «Тебе есть 18?» — после
подтверждения откроется каталог. Добавьте товар в корзину и оформите заказ: покупателю
придёт подтверждение (номер вида `BRO-12`), администраторам — уведомление.

## 5. Админ-панель

`https://ваш-адрес.onrender.com/admin` (или кнопка в боте для администратора).

- **Товары** — название, категория (например: Одноразки / Под-системы / Жидкости), цена,
  старая цена, бейдж (Хит / В тренде / Скидка / В наличии), **вкусы / цвета** через запятую,
  описание, несколько фото. Без фото показывается цветная плашка с короной (6 оттенков).
- **Заказы** — состав, сумма, контакты, статусы (Новый / Связались / Выполнен / Отменён),
  сообщения покупателю прямо из карточки заказа.
- **Вопросы** — вопросы покупателей по товарам и ответы в Telegram.
- **Промокоды** — процент или фиксированная сумма, мин. сумма заказа, лимит использований.

`products.json` содержит актуальный каталог из таблицы «НАЛИЧИЕ KOSHELEV» (вкладка «ДЕВАЙСЫ»):
39 позиций, категории — бренды (Elf Bar, Geek Vape, Vaporesso, Smoant, Voopoo, Lost Vape, Rincoe)
и «Комплектующие». В цене показывается цена со скидкой, прежняя цена зачёркнута, на крупных
скидках (от 10%) стоит бейдж «Скидка». Цвета из таблицы лежат в поле «вкусы / цвета». Фото
добавьте через `/admin`.

## Что в редизайне

- полностью новый визуальный стиль, логотип и тексты под вейп-шоп;
- экран подтверждения 18+ при первом входе (запоминается на устройстве) и предупреждение
  о никотине в подвале и в приветствии бота;
- hero «Зашёл → выбрал → забрал» с преимуществами магазина (600+ отзывов, только оригинал,
  гарантия, без предоплаты, доставка по Москве день в день, самовывоз);
- кнопка «Написать менеджеру» (в приложении и в боте);
- вместо размеров — «вкусы / цвета»; номера заказов — `BRO-…`.

> Перед запуском проверьте требования законодательства вашего региона к продаже и
> дистанционной торговле никотиносодержащей продукцией.

## Постоянное хранилище (важно)

На **бесплатном** плане Render диск не сохраняется между рестартами и деплоями —
`products.json`, `orders.json` и `uploads/` пропадут. Для постоянной работы подключите
платный **Persistent Disk** (блок `disk:` в `render.yaml`) с путём монтирования в корень проекта.

Бесплатный инстанс также засыпает без трафика и просыпается несколько секунд на первом запросе.

## Локальный запуск (по желанию)

```bash
pip install -r requirements.txt
export BOT_TOKEN=your_token
export ADMIN_PASSWORD=secret
export WEBHOOK_URL=https://ваш-туннель.example  # например ngrok
python main.py
```
